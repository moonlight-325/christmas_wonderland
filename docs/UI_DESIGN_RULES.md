# Christmas Wonderland UI 공통 규칙 (v1.9.5 Stage 2)

새 디자인 시스템이 아니라, `widget/pixel_ui.py` 에 이미 있는 규칙을 문서로 정리한 것입니다. 새 UI 는 아래를 따릅니다.

## 기본 단위
- 모든 도형은 `PX`(=2) 정수 격자에 맞추고, 둥근 모서리 대신 계단식 모서리(`pixel_box`)를 씁니다.
- 글자는 Galmuri(`body_font()` 11px, `head_font()` 14px)만 씁니다. 다른 폰트를 지정하지 않습니다.
- 색은 `PAL` 의 이름을 우선 씁니다. 베벨용 밝은/어두운 보조색(`#ffffff`, `#fff1a8` 등)은 `pixel_ui` 안에서만 직접 씁니다.

## 컨트롤 상태 (모든 컨트롤 공통)
| 상태 | 표현 |
|---|---|
| 기본 | 테두리 `border_dark`, 채움 `btn`/`panel` |
| Hover | 채움 `btn_hi`, 테두리 `border` |
| Pressed | 채움 `btn_down` |
| 포커스(키보드) | 테두리 `border` (슬라이더 손잡이는 `gold`) |
| 선택됨(탭/목록) | 채움 `gold` + 베벨, 글자 `shadow` |
| 비활성 | 채움 `btn_off`, 글자·테두리 `dim`. 클릭에 반응하지 않음 |
| 위험(삭제/종료) | `PixelButton(kind="danger")`, 창 닫기는 `red` |
| 키보드 이동 (세로 탭) | Tab 으로 진입, ↑↓/PageUp·PageDown 으로 이전·다음, Home/End 로 처음·끝 (끝에서 멈춤). 포커스는 선택된 줄 안쪽의 어두운 테두리 |

## 사용할 컨트롤
- 버튼 `PixelButton`, 체크 `PixelCheck`, 슬라이더 `PixelSlider`, 세로 탭 `PixelTabs`, 구획 `PixelSection`/`PixelPanel`, 창 `PixelWindow`.
- 표준 Qt 위젯(`QPushButton`, `QSpinBox`, `QLineEdit`, `QListWidget`, `QMenu`, `QMessageBox`)은 전역 스타일시트가 같은 팔레트로 칠하며, 비활성 상태도 위 표와 같게 맞춰져 있습니다.

## 삭제·결과 안내 규칙 (눈사람 공방, 스노우볼 창)
- 되돌릴 수 없는 삭제(눈사람, 스노우볼 전체)는 `ConfirmButton`: 첫 클릭은 글자가 "정말 삭제?"로 바뀌어 3초간 대기, 같은 대상에 한 번 더 누르면 실행. 대기 중 선택이 바뀌거나 창이 닫히거나 버튼이 비활성화되면 대기가 풀린다. 장식 한 개 삭제처럼 쉽게 다시 만들 수 있는 것은 확인 없이 바로 실행하고 결과만 알린다.
- 동작 결과는 한 줄 알림(눈사람 공방 위쪽 `note`, 스노우볼 창 가운데 아래 `note`, 3초 뒤 사라짐)으로 알린다: 추가/복제/삭제/제거 성공, 그리고 최대 개수 때문에 실패한 경우. 한도 문구의 숫자는 코드의 상수(`MAX_GLOBES`, `C.MAX_DECOR`, `M.LIMITS`)에서 가져온다.
- 개수 한도가 있는 목록은 "N / 최대" 를 보여 주고, 가득 차면 금색으로 바꾼다 (스노우볼 목록 `lbl_gcount`, 장식 `lbl_count`).
- 같은 화면을 다르게 다루는 모드는 안내 글머리로 이름을 붙인다: `[보기 모드]`(흔들기) / `[꾸미기 모드]`(장식 배치·이동). 항목이 하나도 없으면 다음 행동을 안내한다.

## 이동·상태 안내 규칙 (장식, 시계, 트레이)
- 끌어서 옮기거나 크기를 바꾸는 동안 커서 옆 툴팁으로 현재 값을 보여 준다: `위치 x, y` / `크기 N배 (W×Hpx)` (문구는 `core.geometry.position_text/scale_text`). 장식 창은 작아서 창 안에 글자를 그리지 않고 툴팁을 쓴다. 놓으면 툴팁을 숨긴다.
- 놓은 위치가 화면 밖이면 `core.geometry.clamp_pos`(48px 이상 보이게)로 가장 가까운 화면 안으로 되돌리고 "화면 밖이라 안으로 되돌렸어요"를 알린 뒤, **보정한 위치를 저장**한다.
- 잠겨서 끌 수 없는 창은 툴팁으로 이유와 푸는 곳을 알리고, 끌 수 있을 때만 이동 커서(`SizeAllCursor`)를 보여 준다.
- 트레이 메뉴 항목은 "다음 동작"(시작/일시정지/재개)을 보여 주므로, 현재 상태는 트레이 툴팁 둘째 줄(`weather.spec.status_summary`)로 알린다. 툴팁은 값이 바뀔 때만 다시 설정한다.

## 설정 창 안내 규칙
- 표시 기준은 저장된 수동값 대 기본값입니다(자동 날씨가 조정 중인 실제 적용값이 아님). 자동 날씨가 값을 계속 움직여도 점이 깜빡이지 않습니다.
- 지금 적용되지 않는(회색) 컨트롤은 값이 달라도 점을 표시하지 않습니다.
- 모든 설정은 바꾸는 즉시 적용되고 저장됩니다(코드 확인: 각 하위 시스템이 `settings.changed` 를 받아 반영). 재시작이 필요한 설정이 생기면 해당 행에 따로 표시해야 합니다. (설정 창 맨 아래 안내 줄과 '기본값과 다른 항목' 표시는 v1.9.6 에서 삭제됨)

## 창
- 보조 창은 `PixelWindow` 를 상속하고, 열 때는 `AppController._present()` 를 거칩니다(기존 인스턴스 재사용 → 복원 → 화면 안 보정 → 앞으로).
- 창 안에서 주기적으로 갱신하는 타이머는 창이 숨겨지면 멈추고 다시 보일 때 시작합니다.

## 피드백 문구
- 저장 실패: 설정·스노우볼은 트레이 알림, 어드벤트는 경고창. 문구는 "무엇이 / 왜 / 무엇을 확인"을 한 번에 적습니다.
- 사용자가 직접 입력한 값이 범위를 벗어나면 저장하지 않고 이유를 알려 줍니다.

- 세로 탭에서 선택된 탭의 아이콘은 모두 어두운 단색입니다. 여러 색이 든 아이콘("장식" 탭의 노란 별)은 선택 시 단색 버전(`star_mono`)으로 바꿔 금색 바탕 위에서 보이게 합니다.
